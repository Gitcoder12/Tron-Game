# Agent Instructions — Tron-Game

Read README.md, CONTRIBUTING.md and FEATURE_UPGRADE_PLAN.md before editing.

- Preserve the current two-player local gameplay unless an issue changes scope.
- Reproduce bugs and identify exact source files before modifying code.
- Keep game logic and rendering concerns separated where practical.
- Add deterministic tests for collisions, state transitions and controls.
- Run browser smoke tests for UI changes and report browser/version.
- Never claim features or cross-browser support not implemented.
- Work on a feature branch and submit a PR; never merge or deploy autonomously.
