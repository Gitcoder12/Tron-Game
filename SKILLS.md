# Agent Skills — Tron-Game

## Game logic audit
Map the game loop, coordinate model, player states and win/loss conditions.

## Collision test design
Create deterministic fixtures for wall, trail, simultaneous and boundary collisions.

## Browser UI engineering
Check input focus, responsive canvas sizing, accessibility and rendering performance.

## Documentation and QA
Explain controls simply and report exact browser and test evidence.

Agents may prepare changes, but human maintainers approve merges and releases.
